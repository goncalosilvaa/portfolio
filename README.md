# Portfolio Dashboard on Vercel

This portfolio is a Vite + React app with a private dashboard for:

- managing projects
- managing skills
- managing client reviews
- tracking visits, CV downloads, project views, and project clicks

## Architecture

- Public app: Vite + React
- Private dashboard: React route at `/dashboard`
- API: Vercel Functions in [`/api`](./api)
- Storage:
  - Postgres on Vercel Marketplace for production
  - local JSON fallback for development when no database URL is configured
- Optional Vercel Web Analytics client script via `@vercel/analytics`

## Environment Variables

Create a `.env.local` file from [`.env.example`](./.env.example).

Required for production on Vercel:

- `DATABASE_URL` or `POSTGRES_URL`
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

Optional:

- `ADMIN_PASSWORD_SALT`

Note: the admin user is only seeded on first initialization. After that, credentials are stored in the database and can be changed from the dashboard.

## Local Development

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

This starts:

- Vite on the frontend
- the local API server on port `3001`

The local Node server now auto-loads `.env.local` and `.env`, so you can point development directly at Neon with `DATABASE_URL`.

If no Postgres connection string is configured, the API uses the JSON files in [`server/data`](./server/data).

## Vercel Deployment

1. Push the repository to GitHub.
2. Import the project into Vercel.
3. Add a Postgres integration from the Vercel Marketplace and attach it to the project.
4. Set `ADMIN_USERNAME` and `ADMIN_PASSWORD` in the Vercel project environment variables before the first production deploy.
5. Deploy.

The project is already prepared for Vercel with:

- API functions in [`api`](./api)
- SPA rewrites in [`vercel.json`](./vercel.json)
- build output generated by `npm run build`
